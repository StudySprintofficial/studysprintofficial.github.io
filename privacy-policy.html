StudySprint Privacy Policy Last updated: August 31, 2026 This Privacy Policy explains how StudySprint Pin Link Finder handles information when it connects to Pinterest. 1. Purpose of the Application StudySprint Pin Link Finder is a personal tool created to help the StudySprint account owner review their own Pinterest Pins and identify Pins that contain outdated destination links. The application is intended for personal use and is not provided as a public service to other users. 2. Information Accessed When authorized through Pinterest, the application may access information from the StudySprint Pinterest account, including: Pinterest Pins Pin titles and descriptions Pin destination links Pinterest board information Other information made available through the Pinterest API that is necessary for the application's stated purpose 3. How Information Is Used Information accessed through Pinterest is used only to: Review StudySprint Pins Identify Pins containing outdated destination links Help the account owner manually update those links The application does not use Pinterest information for advertising, selling data, profiling other users, or providing services to third parties. 4. Data Storage The application is designed for personal use. Pinterest information is not intentionally sold, rented, or shared with third parties. Any information temporarily processed by the application is used only for the purpose described in this Privacy Policy. 5. Third-Party Services The application uses the Pinterest API to access authorized Pinterest account information. Pinterest's own privacy practices and terms apply to information handled by Pinterest. 6. Data Security Reasonable measures are taken to protect application credentials and any information accessed through the Pinterest API. Pinterest authentication credentials, access tokens, and application secrets are not intentionally shared publicly. 7. Data Sharing StudySprint Pin Link Finder does not sell or share accessed Pinterest information with advertisers, data brokers, or other third parties. 8. Data Retention and Deletion Because this application is intended for personal use, Pinterest information is not intended to be retained longer than necessary for the application's purpose. The account owner may stop using the application or revoke its Pinterest authorization at any time. 9. Changes to This Privacy Policy This Privacy Policy may be updated if the application's functionality or data practices change. Any updated version will be published on this page with a new "Last updated" date. 10.
